# Павел Искринский — фронтенд-разработка сайтов

Персональный сайт для заказчиков: [paveliskrinsky.github.io](https://paveliskrinsky.github.io/).

Статический сайт на HTML, CSS и JavaScript без фреймворков, сборки и менеджера пакетов. Публикация — GitHub Pages из ветки `main`.

## Запуск и проверка

Все команды выполняются из корня репозитория.

```bash
python -m http.server 8000
```

Открыть [локальный сайт](http://localhost:8000/) во встроенном браузере Codex. Этот же запуск настроен как `site` в локальном `.claude/launch.json`.

Для проверки HTML нужны Node.js и npm; при первом запуске `npx` потребуется доступ к npm:

```bash
npx html-validate index.html privacy.html 404.html
```

Конфигурация — [.htmlvalidate.json](.htmlvalidate.json). Автоматического набора тестов нет. Каталог `public_html`, сборка и упаковка в `public_html.zip` не настроены.

## Содержание сайта

Порядок разделов: первый экран с полосой доменов проектов → проекты → услуги → отзывы → этапы работы → обо мне и опыт → FAQ → контакты.

- **Первый экран:** равнозначные предложения бизнесу и студиям/дизайнерам — сайт под ключ и фронтенд по Figma; кнопки «Обсудить сайт» и «Обсудить фронтенд», фотография и анимированная полоса восьми доменов из портфолио без https.
- **Проекты:** два клиентских кейса «задача / моя роль / решение / результат», раскрываемые мобильные скриншоты, кнопки заявки и шесть собственных проектов.
- **Услуги:** фронтенд по макету, сайт под ключ, ускорение, доработка и поддержка, доступность, интернет-магазины. У каждой услуги своя кнопка перехода к форме.
- **Отзывы:** цитаты с freelance.ru; до 640 px сначала видны три отзыва, остальные раскрываются кнопкой.
- **Этапы работы:** заявка, оценка и договор, разработка, проверка и запуск.
- **Обо мне:** опыт работы, краткая карьера и сведения о сотрудничестве.
- **FAQ:** семь вопросов о стоимости, сроках, дизайне, CMS, ускорении, оформлении и поддержке.
- **Контакты:** Telegram, e-mail, freelance.ru и форма с согласием на обработку данных.

| Тип | Проекты |
| --- | --- |
| Клиентские | [АО «КемВод»](https://kemvod.ru), [Зеленогорский зоопарк](https://zelzoo.ru) |
| Собственные | [KOMBOS.RU](https://kombos.ru), [Ввези.ru](https://vvezi.ru), [Завели.ru](https://zaveli.ru), [КодРазбор](https://kodrazbor.ru), [OZEK](https://ozek.ru), [АвтоПарам](https://autoparam.ru) |

Светлая и тёмная темы следуют настройкам системы, пока посетитель не выберет тему вручную. Выбор хранится в `localStorage` под ключом `theme`.

## Подготовка ресурсов

Для изображений нужен Pillow с поддержкой AVIF. Для шрифтов — `fontTools` с поддержкой WOFF2 и доступный Arial; путь к Arial задан в `tools/fonts.py`. Скрипты скриншотов, Open Graph и Lighthouse используют локальный Microsoft Edge по пути `BROWSER` из `tools/previews.py`; Lighthouse также требует Node.js и npm.

| Команда | Что делает |
| --- | --- |
| `python tools/images.py` | Пересоздаёт все AVIF/WebP/JPG из `_src/` |
| `python tools/images.py avatar logo projects/autoparam` | Пересоздаёт только перечисленные изображения |
| `python tools/images.py projects/kemvod-mobile projects/zelzoo-mobile` | Оптимизирует мобильные экраны кейсов в ширину 320 px |
| `python tools/previews.py autoparam` | Обновляет исходный скриншот АвтоПарам и его оптимизированные версии |
| `python tools/previews.py --changed` | Сравнивает свежие снимки всех проектов и пересоздаёт изменившиеся |
| `python tools/icons.py` | Пересоздаёт иконки в корне из `_src/logo.jpg` |
| `python tools/og.py` | Рендерит `_src/og.html` в `_src/og.png` и `img/og.jpg`, 1200×630 |
| `python tools/fonts.py` | Скачивает шрифты и печатает CSS, включая метрики запасных шрифтов |
| `python tools/pagespeed.py http://localhost:8000/` | Проверяет локальное портфолио через Lighthouse 12 |
| `python tools/pagespeed.py https://paveliskrinsky.github.io/` | Проверяет опубликованное портфолио через Lighthouse 12 |

`tools/fonts.py` не вставляет напечатанный CSS в страницы автоматически. `tools/icons.py` не изменяет `site.webmanifest`.

Без аргументов `tools/previews.py` обновляет все проекты из `SITES`, а `tools/pagespeed.py` проверяет эти внешние сайты, **не само портфолио**. Для портфолио всегда передавать URL. `--changed` использует точное сравнение пикселей и повторно снимает выбранные для обновления сайты; анимация и реклама могут давать изменения при каждом запуске.

Готовые изображения и иконки не редактируются вручную: сначала меняется исходник или скрипт, затем запускается нужный генератор.

Дополнительные мобильные экраны (`_src/projects/*-mobile.png`) сняты во встроенном браузере Codex. Их обновляют вручную; `tools/previews.py` переснимает только основные экраны из `SITES`.

## Форма и аналитика

Кнопки первого экрана, клиентских кейсов и услуг выбирают задачу через `data-task`, прокручивают страницу к форме и переводят фокус в поле имени, сохраняя уже введённые данные. Нативный и собственный select синхронизированы через событие `change`. Без JavaScript ссылки ведут к форме, услуга выбирается вручную. Доступны все шесть услуг и вариант «Другое».

Форма отправляет данные через Formspree. С JavaScript используется `fetch`, без него — обычный POST. Поле контакта принимает e-mail, `@username` и ссылки `t.me/username` с необязательным префиксом `https://`; формат проверяется нативным HTML `pattern`, а JavaScript уточняет сообщение об ошибке и убирает пробелы по краям перед отправкой. Проверка формата не подтверждает существование адреса или аккаунта. В форме есть обязательные поля, согласие на обработку данных и скрытая ловушка `_gotcha`. Собственного сервера в репозитории нет.

Счётчик Яндекс.Метрики — `113365152`. В коде вызываются следующие цели:

| Идентификатор | Событие |
| --- | --- |
| `form_start` | Первый ввод в форму за открытие страницы |
| `lead` | Успешный ответ сервиса на отправку формы |
| `form_error` | Ошибка отправки |
| `telegram` | Клик по ссылке на `t.me` |
| `email` | Клик по ссылке `mailto:` |
| `freelance` | Клик по ссылке на `freelance.ru` |
| `project` | Клик по внешней ссылке в разделе проектов |
| `faq` | Раскрытие ответа FAQ |
| `reviews_more` | Раскрытие остальных отзывов |

Наличие вызовов в коде не подтверждает настройку целей в кабинете Метрики или доставку письма.
