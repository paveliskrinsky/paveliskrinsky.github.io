# Павел Искринский — разработка и вёрстка сайтов

Персональный сайт для заказчиков: [paveliskrinsky.github.io](https://paveliskrinsky.github.io)

На сайте:

- **Проекты** — клиентские кейсы «задача → что сделал → результат»: АО «КемВод» (kemvod.ru) и Зеленогорский зоопарк (zelzoo.ru); компактной сеткой собственные проекты KOMBOS.RU (kombos.ru), Ввези.ru (vvezi.ru), АвтоПарам (autoparam.ru) и КодРазбор (kodrazbor.ru)
- **Отзывы** — цитаты заказчиков с freelance.ru
- **Как я работаю** — этапы от заявки до запуска
- **Обо мне** — кратко об опыте и короткая лента мест работы
- **Чем могу помочь** — вёрстка по макету, сайт под ключ, ускорение, доработка и поддержка, доступность, интернет-магазины
- **Частые вопросы** — стоимость, сроки, CMS, оформление работы
- **Контакты** — Telegram, e-mail, профиль на freelance.ru и форма заявки

## Стек

Один файл `index.html`: HTML, CSS и ванильный JavaScript без фреймворков и сборки. Картинки в AVIF/WebP/JPG с `srcset`: исходники лежат в `_src/`, оптимизированные версии собираются в `img/` скриптами `python tools/images.py` и `python tools/previews.py` (скриншоты проектов) и `python tools/og.py` (картинка для превью ссылки), замеры Lighthouse — `python tools/pagespeed.py`. Светлая и тёмная тема по системным настройкам, адаптив под мобильные. Форма работает через Formspree, хостинг — GitHub Pages.
