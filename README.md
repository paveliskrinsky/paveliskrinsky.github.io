# Павел Искринский — разработка и вёрстка сайтов

Персональный сайт для заказчиков: [paveliskrinsky.github.io](https://paveliskrinsky.github.io)

На сайте:

- **Работал с** — статичный список клиентов и студий под первым экраном
- **Проекты** — клиентские кейсы «задача → что сделал → результат»: АО «КемВод» (kemvod.ru) и Зеленогорский зоопарк (zelzoo.ru); компактной сеткой собственные проекты KOMBOS.RU (kombos.ru), Ввези.ru (vvezi.ru), Завели.ru (zaveli.ru) и КодРазбор (kodrazbor.ru)
- **Чем могу помочь** (в меню «Услуги») — вёрстка по макету, сайт под ключ, ускорение, доработка и поддержка, доступность, интернет-магазины
- **Отзывы** — цитаты заказчиков с freelance.ru, на телефоне три и кнопка «ещё»
- **Как я работаю** — этапы от заявки до запуска
- **Обо мне** — кратко об опыте и короткая лента мест работы
- **Частые вопросы** — стоимость, сроки, CMS, оформление работы
- **Контакты** — Telegram, e-mail, профиль на freelance.ru и форма заявки с согласием на обработку данных
- **Политика конфиденциальности** — отдельная страница `privacy.html`, ссылка в футере и у формы

## Стек

Главная — один файл `index.html`: HTML, CSS и ванильный JavaScript без фреймворков и сборки. `privacy.html` и `404.html` используют общий `page.css`. Шрифты Manrope и Unbounded лежат в `fonts/` (скачиваются скриптом `python tools/fonts.py`, он же считает метрики запасных шрифтов против сдвига вёрстки), есть `robots.txt` и `sitemap.xml`. Картинки в AVIF/WebP/JPG с `srcset`: исходники лежат в `_src/`, оптимизированные версии собираются в `img/` скриптами `python tools/images.py` и `python tools/previews.py` (скриншоты проектов) и `python tools/og.py` (картинка для превью ссылки), замеры Lighthouse — `python tools/pagespeed.py`. Светлая и тёмная тема по системным настройкам, адаптив под мобильные. Форма работает через Formspree, цели Метрики: `lead` (отправка формы), `telegram`, `email` (клики по контактам). Хостинг — GitHub Pages. Проверка разметки: `npx html-validate index.html privacy.html 404.html`.
