## Этап 3. Надёжность и доступность

- [x] **Контент без JS.** `.reveal` (index.html:1654) прячет контент через `opacity: 0`, показывает его только IntersectionObserver. Без JS, в режиме чтения и при сбое скрипта всё ниже hero пустое.
  ```html
  <script>document.documentElement.classList.add('js')</script>
  ```
  ```css
  .js .reveal { opacity: 0; transform: translateY(28px); }
  ```
  Ещё лучше перейти на `animation-timeline: view()` внутри `@supports` и оставить JS только как запасной путь. Не сломать правила `prefers-reduced-motion` (index.html:1842–1859).
- [x] **Стили печати `@media print`.**

  - Скрыть `nav`, `.sticky-cta`, `.orb`, `.marquee`, `.page-bg` и форму.
  - Показать `.reveal`, раскрыть `details`.
  - Выводить адреса проектов текстом, например через `a[href^="http"]::after { content: " (" attr(href) ")" }` для ссылок проектов.
- [x] **Skip-ссылка.** Добавить «К содержимому» первым элементом `body` со ссылкой на `#main`, видимую по фокусу. Сейчас до контента 9 фокусируемых элементов.
- [x] **Статус формы.** `#form-status` (index.html:2510) держать видимым и пустым, менять только текст. Сейчас `hidden` снимается одновременно с вставкой текста, и часть скринридеров такое не озвучивает.
